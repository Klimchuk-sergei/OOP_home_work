# Категории и товары (Product & Category)

Учебный проект на Python, реализующий простую модель категорий товаров с использованием классов и тестов.

## 📦 Описание

Проект включает две основные сущности:

- `Product` — класс для описания товара (название, описание, цена, количество).
- `Category` — класс для описания категории (название, описание, список товаров).

Также реализована функция `load_json()`, загружающая категории и товары из JSON-файла `products.json`.

## ✅ Возможности

- Инициализация объектов классов `Product` и `Category`.
- Автоматический подсчёт количества созданных категорий и всех товаров.
- Загрузка данных из JSON.
- Покрытие тестами >75%.

## Новая функциональность

- Добавлены два подкласса продукта: `Smartphone` и `LawnGrass`.
- Добавлена проверка на совместимость при сложении товаров (должны быть одного класса).
- Метод `add_product` теперь защищён: разрешено добавлять только объекты-наследники `Product`.
